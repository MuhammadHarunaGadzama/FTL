# FTL Coins

Premium Telegram Mini App foundation.

## Includes
- Mobile-first FTL Coins interface
- Telegram Mini App detection
- Server-side Telegram initData verification
- Supabase database schema
- Real 12-hour mining cooldown endpoint
- 0.005 FTL mining reward
- Referral endpoint
- Wallet-ready balance model
- Health endpoint

## Environment
Copy `.env.example` to your deployment settings. Never expose `TELEGRAM_BOT_TOKEN` or `SUPABASE_SERVICE_ROLE_KEY` in client code.

Run `npm install`, then `npm run dev`.
